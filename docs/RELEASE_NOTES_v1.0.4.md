# ESP32-S3 DNS Server v1.0.4 · 更新说明

> 本文档由 AI 整理生成。

目标硬件：**ESP32-S3 N16R8**。固件源码中的 `PROJECT_VER` 已更新为 `1.0.4`。

## 本次版本变化

- 增加内网 IP 的 DNS PTR 反向解析本地处理，避免未配置的私有地址反向查询直接转发到公共上游。
- 覆盖 RFC 1918 私有 IPv4（`10/8`、`172.16/12`、`192.168/16`），并处理 IPv4 环回、链路本地、CGNAT，以及 IPv6 ULA、链路本地的对应反向区域。
- 已配置的本地记录、显式过滤/重写规则优先；未命中的私有地址 PTR 查询直接返回 `NXDOMAIN`。公网地址 PTR 解析与其他 DNS 查询保持原有逻辑。
- 未修改 Flash 分区表、OTA 布局、规则镜像格式、NVS 数据格式。
