# 第一次使用：从烧录到局域网 DNS 生效

> 本文档由 AI 整理生成。

## 1. 先确认设备真正启动

连接 USB 数据线，串口波特率通常为 115200。启动日志应先出现 ESP32-S3 ROM、ESP-IDF bootloader、16 MB Flash、8 MB PSRAM 初始化，再出现应用日志。**有 Wi-Fi 热点、能够 ping 192.168.4.1 并不等于 HTTP/DNS 已成功启动**：必须再观察是否出现 `web server failed to start`、`DNS server failed to start` 或异常重启。

### 期望首次启动状态

- 没有保存 Wi-Fi 时，创建 `ESP32-DNS-XXXX`；默认密码 `esp32dns`（可在编译配置里修改）。
- ESP32 SoftAP 默认网关为 `192.168.4.1`，一般给终端分配 `192.168.4.x` 地址。
- 浏览器访问 **http://192.168.4.1/**（不是 HTTPS；此时可能还没有证书）。
- 配置门网页应显示 Wi-Fi 设置界面；如果没有自动弹出，关闭移动网络“智能切换”、手动输入 URL，不依赖自动强制门户检测。

## 2. 加入家庭 Wi-Fi

1. 手机/电脑连接 `ESP32-DNS-XXXX`，确认拿到 `192.168.4.x`。
2. 打开 `http://192.168.4.1/`，进入系统 Wi-Fi 设置页。
3. ESP32-S3 只支持 **2.4 GHz Wi-Fi**。输入 SSID 和密码；路由器只广播 5 GHz 时无法连接。
4. 推荐在路由器 DHCP 中固定分配此设备地址，或者设置**不会冲突的静态 IP**。不要把设备 IP 改到错误网段，也不要把 DNS 服务器的上游设成自己，避免解析环路。
5. 保存、确认路由器已分配地址；切回家庭 Wi-Fi，从新的 LAN 地址访问 Web。
6. 设置管理密码；之后再配置上游、规则、重写与加密 DNS。

使用静态 IP 时填入当前网段的真实网关与掩码。例如所在网络为 `192.168.31.0/24` 时，可考虑为设备分配 `192.168.31.53/24`，网关按实际三层路由器地址填写；这里只是例子。

## 3. 配置上游 DNS

默认上游是公共 IPv4 DNS。可以使用一条或多条：

```text
223.5.5.5
119.29.29.29
tcp://119.29.29.29
tls://dns.alidns.com
https://doh.pub/dns-query
```

明文 IP 上游一般无需 bootstrap；DoH/DoT 主机名需要先解析其 IP，设备提供独立 bootstrap 配置以避免循环。要使用 DoH/DoT 上游还须保证时间同步成功、证书链验证可用，以及实际网络可以连接对应地址与端口。

**上游 DoH/DoT 与设备对外提供的 DoH/DoT 是两回事。** 前者不需要上传你自己的服务器证书；后者需要。

## 4. 添加过滤订阅

在「过滤规则 → 订阅列表」选择需要的规则，如 AdGuard DNS Filter / AdAway / anti-AD。点击保存后再「检查更新」；下载、编译、写 Flash、激活需时间，过程中不要断电。默认只启用 AdGuard DNS Filter；若网络无法访问其托管站点，可暂时改用本地可达的规则源。

更新后的规则不一定会立刻拦截每个 DNS 查询：请先检查「过滤保护」已开启、实际域名是否命中、白名单是否覆盖，以及设备/路由器是否仍在使用其他 DNS。

## 5. 本地解析与设备 DNS 验证

在「本地解析」添加：

```text
nas.home.arpa A 192.168.31.88
nas.home.arpa AAAA 2001:db8::88
```

Windows 命令行：

```powershell
nslookup nas.home.arpa 192.168.31.53
nslookup -type=AAAA nas.home.arpa 192.168.31.53
```

Linux：

```bash
dig @192.168.31.53 nas.home.arpa A
dig @192.168.31.53 nas.home.arpa AAAA
dig +tcp @192.168.31.53 nas.home.arpa A
```

务必把命令里的 `192.168.31.53` 改成 ESP32 的实际地址。若显式指定 ESP32 DNS 可以查询，但浏览器广告过滤没有生效，请检查路由器的 DHCP DNS 下发设置、浏览器安全 DNS/私有 DNS 及终端缓存。**本项目并不会强制劫持局域网其他设备的 DNS 查询。**

## 6. 配置设备对外的 DoH/DoT（可选）

上传 PEM 证书和匹配的 PEM 私钥，成功保存后设备重启/重载。之后检查 `https://dns.example.net/dns-query`、TCP 853 是否监听。证书必须包含客户端实际连接的域名 SAN；只有 IP 且无匹配 SAN 的自签证书通常不会被正常客户端信任。详细验证见 [TLS/安全](TLS_AND_SECURITY.md)。

## 7. 首次使用验收

- [ ] 上电不重启、PSRAM 初始化成功。
- [ ] 能从手机打开 SoftAP 的 `http://192.168.4.1/`。
- [ ] 连接 LAN 后固定 IP 可以 ping 且 Web UI 可访问。
- [ ] UDP A、AAAA 查询和 TCP DNS 查询能成功。
- [ ] 本地重写返回预期地址，规则拦截和例外均符合预期。
- [ ] 强制更新订阅成功；断网失败时仍保留旧规则。
- [ ] 设置管理密码；未授权访问 API 被拒绝。
- [ ] 若启用 DoH/DoT，证书校验和实际 TLS 握手成功。

遇到问题按 [故障排查](TROUBLESHOOTING.md) 的顺序检查，附上**第一条错误日志**，而非只看最后设备重启时的输出。
